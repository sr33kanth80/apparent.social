# apparent

Make your real work apparent to the investors who fund builders.

```bash
npx apparent
```

Run it in a repo (or point it at your whole workspace) and `apparent` turns your
build activity into a brag-worthy build card and a ready-to-claim founder profile
on [apparent.social](https://apparent.social).

Then find investors you can email right now — matched to what you're building:

```bash
npx apparent findinvestors
```

**Your code never leaves your machine.** `apparent` reads only local git
stats (commit cadence, languages, project READMEs you choose to share) — never
your source code — and nothing is uploaded until you review and confirm it.

> `v0.0.1` is a placeholder release. The full CLI is on the way — see the build
> blueprint in the Apparent repo (`cli/BLUEPRINT.md`).
