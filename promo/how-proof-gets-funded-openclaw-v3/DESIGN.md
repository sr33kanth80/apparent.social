# Apparent OpenClaw V3 Promo

## Finishing pass (SFX + emoji)
This project existed fully illustrated and narrated but unrendered, with no SFX and no emoji. Finished it: added ~20 SFX cues (mechanical keyboard typing burst for the `$ npx apparent` command, card/pin pops, a wood-stamp confirm for "MATCH CONFIRMED," chat-bubble pops, an Apple-style click, and a bell finale) and tasteful emoji on every kicker/CTA label. Rendered for the first time to `../how-proof-gets-funded-openclaw-animated-promo-v3.mp4` (~20s). No new illustrations were generated — the image-gen service connected in this environment had 0 credits.

## Style Prompt

Create a quick, polished vertical Apparent promo that feels like a warm illustrated launch film, not a generic SaaS reel. Use the existing OpenClaw proof illustrations as cinematic backplates, with large confident type, tactile paper texture, animated proof cards, map routes, and mascot motion. The mood should be crisp, founder-friendly, and premium enough for VCs without feeling corporate.

## Colors

- Paper: `#fbf7ee`
- Ink: `#201a14`
- Clay: `#c66a3d`
- Moss: `#84a86a`
- Sky: `#6fa7c8`
- Gold: `#f0c75d`

## Typography

- Display: `Georgia`, 850-900 weight, tight tracking for major claims.
- Data/UI: `IBM Plex Mono`, 600-700 weight for command lines, proof labels, and route tags.
- Body: system serif fallback only for tiny supporting lines if needed.

## Motion Rules

- Snappy, layered entrances with varied eases.
- Use warm light-leak crossfades between scenes.
- Let the mascot bob, blink, point, travel, and react, but keep the product message readable.
- Keep every important line on screen long enough to read in under two seconds.

## What Not To Do

- Do not use neon, cyberpunk, or dark-blue SaaS styling.
- Do not make the reel feel like a static slideshow.
- Do not copy any specific animation studio style.
- Do not hide the command `npx apparent` in tiny footer text.
