# Fonts Directory

Place the following font files here:
- `tt-norms-pro-regular.woff2` (weight 400)
- `tt-norms-pro-semibold.woff2` (weight 600)

You can download TT Norms Pro from:
- https://www.fontshare.com/ (free alternatives)
- Or use a similar font like Inter or DM Sans as a fallback

If you don't have these fonts, the page will fall back to system fonts.
